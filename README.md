# Pepper.ru — актуальная цена в Беларуси

Userscript для Tampermonkey / Violentmonkey: показывает на Pepper.ru цену товара
с Ozon.by и Wildberries.by, пересчитанную в российские рубли по курсу НБРБ.

## Установка

1. Установите Tampermonkey или Violentmonkey.
2. Откройте [pepper-by-price.user.js](https://raw.githubusercontent.com/dykomenko/pepper-by-price/main/pepper-by-price.user.js) — менеджер скриптов предложит установить.
3. При первом запуске разрешите запросы к внешним доменам (`@connect *`).

Обновления подтягиваются автоматически (`@updateURL`) при росте `@version` в этом репозитории.

## Как работает

1. Проверка идёт **в фоне, без вкладок**: скрипт проходит по ссылке скидки, определяет товар
   и запрашивает цену и наличие у Ozon.by / Wildberries.by.
2. Если товара нет в наличии, показывается «Нет в наличии» (а не таймаут).
3. Если фон не сработал (антибот магазина), появляется кнопка «Через вкладку» — она открывает
   магазин во вкладке и читает цену со страницы. В меню скрипта можно включить автооткрытие вкладки.

## Релиз обновления

Поднимите `@version` в `pepper-by-price.user.js` и сделайте push в `main`.
